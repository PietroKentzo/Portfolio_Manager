# AI Portfolio Manager

An AI-powered multi-agent portfolio analysis system that performs daily research on a stock portfolio and produces structured *BUY / HOLD / REDUCE / SELL* recommendations.

The system combines *fundamental analysis, market news & macro research, and technical analysis* through specialized AI agents before passing the results to a final Portfolio Manager agent.

Rather than making decisions from a single prompt, the project separates research responsibilities across multiple agents and maintains historical investment theses so that recommendations can evolve consistently over time.
